# Event analysis — three authorized frontend explorations

## Product and language
Swedish event-analysis workspace for people assessing news/event text. Preserve the working flow: paste source text → Analysera → live workflow progress → Sammanfattning with interactive verified text evidence. Existing workflows are risks, reach and service. Source text and evidence must remain distinguishable; labels and guidance should be Swedish.

The user explicitly asks for a total of three iterations, each on a separate branch/worktree. Create distinct compositions and motion behaviors, not just recolorings. These are authorized alternatives; the existing warm yellow theme is not a visual constraint.

## Shared behavior and quality
Preserve streaming APIs, request guards, health dialog, navigation eligibility, exact evidence matching, keyboard selection and screen reader status. Keep actual data separate from sample/demo data. Do not imply saved history, integrations, alerts or analytics exist unless implemented. Functional sample-text widgets and text-derived counts are reasonable exploration features.

Use legible body type, strong headline hierarchy, clear boundaries, comfortable spacing, visible focus, and responsive layouts. Use accessible native controls; collapse columns appropriately on narrow screens and allow scrolling rather than cropping content. Honor prefers-reduced-motion for all animations and transitions. No available custom logo is imported in current source; do not substitute a fabricated institutional logo.

## 01 Signal
Direction: dark teal operations workspace with lime accents. Base #071b1b, elevated #102b2b, text #eaf4ee, secondary #9eb7af, primary #c5f06b, borders #294743. Dense but readable command-center composition; compact sidebar/rail, prominent event composer, workflow monitor and source context widgets. Use subtle grid ambience, staggered entrance, modest card elevation on hover and animated status/progress. Avoid motion that distracts from reading. Evidence colors must retain readable dark text or appropriately contrasting marks.

## 02 Editorial
Direction: calm ivory/terracotta editorial analysis desk. Base #f5f1e8, cards #fffdf8, ink #282c29, secondary #74746a, accent #bd543a, border #ddd7ca. Large serif headline paired with system sans body; magazine-like columns, numbered process explanations, generous rules and margins, structured source/sample panel. Use soft reveal, understated button underline/offset and restrained disclosure motion. Prioritize reading the original article and checking evidence.

## 03 Atlas
Direction: blue/periwinkle analytical studio. Base #f2f5fc, cards #ffffff, ink #202e54, secondary #7180a0, primary #4263eb, accent #a5a3f5, border #dfe5f4. Modular dashboard with rounded widgets, compact overview labels, icon treatments, crisp composer and workflow cards. Use gentle slide/fade transitions, animated progress and tactile hover/focus states. Distinguish from Signal with bright surfaces and from Editorial with structured modular geometry.

## Asset and dependency constraints
Current UI is React/TypeScript with vanilla CSS and native embedded SVGs. Favor CSS-generated decoration and system fonts; adding UI dependencies is unnecessary. Existing unused hero and starter framework SVGs are not product branding. No stock photo is necessary for these functional dashboards.
